# @repo/virtual-authenticator-agent

This package implements the client/browser-side half of a WebAuthn ceremony — the logic that normally lives inside a user agent (browser) when it calls `navigator.credentials.create()`/`.get()` — as a counterpart to `@repo/virtual-authenticator`, which implements the authenticator-side half. `VirtualAuthenticatorAgent` (`IAuthenticatorAgent`) takes browser-shaped `CredentialCreationOptions`/`CredentialRequestOptions`, performs the agent-side WebAuthn algorithm steps (origin/RP ID validation, credential selection, hashing client data), then drives an injected `IAuthenticator` instance to produce the actual attestation/assertion, mapping authenticator exceptions (e.g. user presence/verification required, credential not found) into agent-level exceptions along the way.

It also owns WebAuthn extension processing (`extensions/`, e.g. `credProps`) via an `ExtensionRegistry`/`ExtensionProcessor` pipeline that runs alongside the core ceremony. In short: `virtual-authenticator` answers "what would the authenticator do," and this package answers "what would the browser do to talk to that authenticator" — together they let a caller (such as the browser extension or `api-bff`) simulate an entire WebAuthn registration or authentication round-trip server-side without a real browser or hardware key.

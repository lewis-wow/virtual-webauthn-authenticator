# @repo/virtual-authenticator

This package is the cryptographic and protocol core of the project: a W3C WebAuthn Level 3 / CTAP2-compliant virtual authenticator. It implements the `authenticatorMakeCredential` and `authenticatorGetAssertion` operations against `IAuthenticator`, handling credential exclusion, key generation delegation (`IKeyProvider`), attestation statement production, authenticator data assembly, and signing over the client data hash — everything a real hardware authenticator would do, but running server-side. It also owns the full WebAuthn wire-format concerns: CBOR-encoded attestation objects and authenticator data parsing (`cbor/`), Zod validation/DTO schemas mirroring the spec's structures (`validation/`, `dto/`), attestation format handlers for `none` and `packed` (`attestationHandlers/`), and a state machine for multi-step ceremonies requiring user presence/verification (`state/`).

Its `browser/` subfolder is a separate concern: polyfill-style implementations of the browser-side WebAuthn interfaces (`PublicKeyCredential`, `AuthenticatorAttestationResponse`, `CollectedClientData`, etc.) used to convert between browser-shaped ceremony options/responses and this package's internal types. This package has no opinion on where private keys live or how they're stored — that's provided by an injected `IKeyProvider` (see `@repo/key-vault`) — and no opinion on client/agent-side orchestration, which is layered on top by `@repo/virtual-authenticator-agent`.

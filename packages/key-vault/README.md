# @repo/key-vault

This package is the `IKeyProvider` implementation backing the virtual authenticator with Azure Key Vault, so that credential private keys are generated and used inside the vault (optionally HSM-backed) and never exist as raw material in application memory. `AzureKeyVaultKeyProvider.generateKeyPair` creates an EC or RSA key in Key Vault for a given WebAuthn credential and returns its CBOR-encoded COSE public key plus Key Vault metadata (key ID/name) to persist alongside the credential; `sign` looks up that metadata, calls Key Vault to sign over the authenticator's data-to-sign, and converts the result from JOSE to the DER signature encoding WebAuthn requires for ECDSA algorithms (via `ecdsa-sig-formatter`). OKP (Ed25519) keys are explicitly unsupported since Azure Key Vault doesn't offer them.

`CryptographyClientFactory` centralizes construction of the per-key Azure `CryptographyClient` used for signing. In local development this is exercised against the Lowkey Vault emulator (see the root README's Azure Key Vault docs and `.lowkey-vault/`) rather than a real Azure resource, so the same `IKeyProvider` contract is testable without live cloud credentials.
